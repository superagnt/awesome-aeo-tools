# Awesome AEO tools

AEO and AI visibility tools compared, every price checked and dated: each tool's MCP server, API and CLI, its entry plan and the AI engines it tracks, read from its own pages.

[superagnt](https://superagnt.com) makes [supereo](https://supereo.app), one of the tools in this list, and keeps the list. supereo (supereo.app) is an AI agent that does everything it takes to get your brand recommended by ChatGPT, Gemini, Perplexity, Claude and Google, on your site and off it: site fixes, new pages, roundups, placements and video. It proves what worked against control prompts. Made by superagnt.

## What's compared

What your agent can use, and what it costs to start:

- **MCP server**: a Model Context Protocol server from the vendor that reaches the tool's AI visibility data, so Claude, ChatGPT, Cursor or another agent can ask it.
- **API**: an API from the vendor that serves that data.
- **CLI**: a command-line tool the vendor ships for it.
- **Entry plan**: its cheapest paid plan that tracks AI answers, as a price a month on monthly billing, or a month of the yearly price where the page bills only yearly. A free plan, where there is one, is noted beside it, and a plan whose page shows no price says so.
- **AI engines**: the AI assistants and AI search features its pages say it tracks, by their common names.
- **Checked**: the day its pages were read.

Each Yes, price and engine list links to the tool's own page it was read from, and [data.json](data.json) holds the words on that page behind it. A No means none of the tool's pages read that day offers one: a vendor's MCP server or API that serves only its other products' data is a No here. A note beside a value is the plan it takes or the limit the entry plan sets.

## The order

supereo first, since superagnt makes it. Then the tools with an MCP server, then those with an API, then those with a CLI, then the rest, each group A to Z.

## How it's kept

Every value is read from the tool's own pages on the day in its Checked column: its pricing page for its entry plan, and its own product pages and docs for its MCP server, API, CLI and engines. Nothing comes from another site's list or table. Prices are as each page states them, in its currency. [data.json](data.json) is the source, and `node build.mjs` writes the table above from it.

Something wrong or out of date? Open an issue with the tool's own page that shows it.
